How these numbers are calculated

This run is scored against NIFC fire perimeters — hotspots are not used.

  • Predicted: where the forecast's time of arrival is within the horizon.
  • Actual: the NIFC perimeter mapped closest to run time + horizon (timed by its last edit when it has no reliable mapped time).
  • Growth only: the latest perimeter mapped before the run is removed from both, so only new spread counts.

Precision = overlap ÷ predicted growth
Recall = overlap ÷ actual growth
IoU = overlap ÷ area either one covers

A horizon is shown only when the fire grew at least 10 acres, a perimeter was mapped (or last edited) within 3h of it, and at most 10% of the growth fell outside the forecast's area — the metrics report's default filters.
